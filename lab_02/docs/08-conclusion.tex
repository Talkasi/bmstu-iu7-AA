\chapter*{\hfill{\centering  ЗАКЛЮЧЕНИЕ}\hfill}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В ходе исследований получено, что среди анализируемых алгоритмов при больших размерностях матриц (более 5) самым эффективным является оптимизированный алгоритм Винограда, а стандартный алгоритм Винограда работает быстрее стандартного алгоритма умножения матриц.

Цель данной работы была выполнена. 
Для достижения поставленной цели были выполнены следующие задачи:
\begin{itemize}[label=---]
	\item описаны вышеперечисленные алгоритмы умножения матриц;
	\item написана программа, реализующая вышеперечисленные алгоритмы умножения матриц;
	\item проверена работоспособность программы, выполнено модульное тестирование;
	\item проведён анализ временных затрат вышеперечисленных алгоритмов.
\end{itemize}
