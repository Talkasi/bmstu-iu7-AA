\chapter*{\hfill{\centering ВВЕДЕНИЕ}\hfill}

\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}
Целью данной работы является исследование стандартного алгоритма умножения матриц, а также стандартного и оптимизированного алгоритмов Винограда.

\label{sec:goals}
Для достижения поставленной цели необходимо выполнить следующие задачи:
\begin{itemize}[label=---]
	\item описать вышеперечисленные алгоритмы умножения матриц;
	\item написать программу, реализующую вышеперечисленные алгоритмы умножения матриц;
	\item проверить работоспособность программы, выполнив модульное тестирование;
	\item провести анализ временных затрат вышеперечисленных алгоритмов.
\end{itemize}
