\chapter{Технологический раздел}
\section{Средства реализации}
Алгоритмы для данной лабораторной работы были реализованы на языке C++ при использовании компилятора gcc версии 13.3.1, так как в стандартной библиотеке приведённого языка присутствуют все необходимые структуры данных для реализации требуемых алгоритмов умножения матриц.

\section{Реализация алгоритмов}
Листинги исходного кода функций стандартного умножения матриц, а также стандартного и оптимизированного алгоритмов Винограда представлены в приложении~\ref{a:appendices}.
