# Шаблон лабораторной работы по курсу Анализ алгоритмов (сокращенная форма)

Этот шаблон предназначен для выполнения отчетов по курсу Анализ алгоритмов в сокращенном виде (начиная с лабораторной работы 4). 
Необходимо изменить содержимое файлов `report/title.tex`, `report/content.tex` на собственное. 
В файле `report/biblio.bib` размещаются данные об источниках. 

## Зависимости

За основу взяты репозитории https://github.com/kormanowsky/bmstu-assignment и https://github.com/Orianti/bmstu-latex-class.
В последнем репозитории разработан `Latex`-пакет `bmstu`, его нужно установить себе по инструкции из репозитория. 
Также естественно нужны `make`, `pdflatex`, `biber`. 

## Сборка

В папке `report/`:

- `make report.pdf` - собрать отчет
- `make clean` - очистить временные файлы, оставить `.pdf`
- `make cleanwpdf` - очистить все, в т. ч. `.pdf`
